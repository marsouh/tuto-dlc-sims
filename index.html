DLC Sims 4 PC

Pré-requis

Avant de commencer tu auras besoin de :
- Windows 10 ou Windows 11
- Le jeu The Sims 4, gratuit sur EA, lance le jeu au moins une fois avant de continuer
- Une connexion Internet stable
- Les droits d'administrateur sur votre pc
- Environ 80 Go d’espace disque libre (pour l’installation complète des DLC)

Étape 1 : Télécharger l'updater

Télécharge l’updater en cliquant ➜ ici.

  • Dézippe le fichier, puis ouvre le en tant qu’administrateur.
  • Vérifie que le bon fichier du jeu est bien sélectionné.
    Si ce n’est pas le cas, sélectionne-le toi-même en cliquant sur Browse (généralement : C:\Program Files\EA Games\The Sims 4).
  • Clique sur Update.
  • Mets Yes si tu as obtenu le jeu de façon légitime.
  • Sélectionne les DLC que tu veux télécharger.

Si ça ne fonctionne pas télécharges les dlc manuellement ➜ DLC Sims 4 DATABASE

Étape 2 : Télécharger l'unlocker

Télécharge l’unlocker en cliquant ➜ ici.

  • Dézippe le fichier, puis ouvre setup.bat en tant qu’administrateur.
  • Choisis Install EA DLC Unlocker en appuyant sur 1.
  • Sélectionne Add/Update Game Config en appuyant sur 2.
  • Choisis The Sims 4 en appuyant sur 21 ou 14, selon la version de l’unlocker.

Cette étape est à refaire à chaque fois que tu veux jouer (avant de lancer le jeu).

DLC Database PC

Si tu veux télécharger les DLC, clique là ➜ DLC Sims 4 DATABASE

  • Les fichiers sont des fichiers ZIP, il faut les extraire et les placer les dossiers dans le répertoire de The Sims 4.
    Le dossier de ton jeu se trouve généralement ici :
    Pour Steam : C:\Program Files (x86)\Steam\steamapps\common\The Sims 4
    Pour Origin: C:\Program Files\EA Games\The Sims 4
    Si tu as la flemme de chercher; télécharge et exécute ce fichier ➜ DLC Fichier Sims
    Double clic dessus pour ouvrir le fichier
  • Prends les dossiers à l’intérieur du fichier que tu viens d’extraire et place-les dans le répertoire The Sims 4.
    Si Windows affiche : « Remplacer les fichiers dans la destination ? » ➜ choisissez Remplacer.

⚠️ Ne renomme jamais les fichiers, sinon ça ne fonctionnera plus.

C'est comme ça qu'on procède pour installer un DLC manuellement, il faut le télécharger, l'extraire et le glisser dans le répertoire du jeu.

Si ça ne fonctionne pas télécharges les dlc manuellement ➜ DLC Sims 4 DATABASE

Étape 2 : Télécharger l'unlocker

Télécharge unlocker en cliquant ➜ ici.

  • Dézippe le fichier.
  • Fais un clic droit / Ctrl + clic sur Prepare DLC Unlockers, puis sélectionne Open.
  • Si tu obtiens le message “Apple ne peut pas vérifier si l’app contient des logiciels malveillants”, fais ça : Réglages Système > Confidentialité et sécurité > Sécurité > Ouvrir > Ouvrir quand même.
  • Lance l’EA App (clique sur OK si une erreur concernant le port 3216 apparaît).
  • Lance le jeu

Télécharge les fichiers DLC si nécessaire (en cliquant sur le lien dans DLC DATABASE MAC) Lance l’EA App (clique sur OK si une erreur concernant le port 3216 s’affiche).

Cette étape est à refaire à chaque fois que tu veux jouer (avant de lancer le jeu).

⚠️ Note importante pour Les Sims : oui, tu as besoin des fichiers DLC. Le DLC Unlocker ne télécharge rien.

Les mises à jour de l’EA App et du jeu n’ont aucun impact sur ce DLC Unlocker. Lorsqu’un nouveau DLC sort, le DLC Unlocker met normalement à jour la configuration du jeu et t’en informe. Si ce n’est pas le cas, retélécharge le DLC Unlocker. Si le DLC n’est toujours pas débloqué, il est probablement pas encore disponible.

FAQ

🎀 Virus détecté ?

Si ton antivirus détecte quelque chose, évite de le désactiver. Supprime le fichier et retélécharge uniquement depuis une source officielle. Tu peux aussi vérifier le fichier avec un service de scan (ex: VirusTotal) et lire le rapport.

🎀 COMMENT ON DÉZIPPE ?

Sur Windows : clic-droit sur le fichier → Extraire tout. Sinon, installe 7-Zip ou WinRAR puis clic-droit → Extraire.

🎀 Ça marche avec les Sims EA et/ou Origin ?

Ça dépend de la version et de la méthode utilisée. Le plus fiable reste d’utiliser les options officielles de l’appli EA / Origin et les contenus obtenus légalement.

🎀 C'est long à télécharger… ça fait 20 minutes…

Oui c’est possible : ça dépend de ta connexion Internet, de ton disque (SSD/HDD), et de ce qui tourne en arrière-plan.

🎀 Mon jeu n’est pas détecté

Vérifie que tu pointes vers le bon dossier d’installation du jeu. Si besoin, sélectionne-le manuellement via Parcourir / Browse.

🎀 L’installation échoue
  • Vérifie ta connexion Internet.
  • Assure-toi d’avoir assez d’espace libre (le jeu peut être très lourd).
  • Lance le programme en tant qu’administrateur.
  • Si l’antivirus bloque, ajoute une exception uniquement si la source est officielle et fiable.
🎀 Les DLC ne s’affichent pas en jeu
  • Lance une réparation du jeu via le launcher officiel.
  • Redémarre le jeu (et l’appli EA / Origin si besoin).
  • Vérifie que ton contenu est bien installé et reconnu côté launcher.
🎀 Erreurs d’archives multipart (part1, part2, etc.)

Utilise 7-Zip : mets toutes les parties dans le même dossier, puis extrais depuis le fichier .part1.
